この数字の読み方
・Search Console のデータは2〜3日遅れます。直近が空なのは正常です。
・上の4つの数字は Search Console の画面とぴったり同じです（総数で引いています）。 　いっぽうクエリ別・ページ別の表を足した数は、画面の総数より小さく出ます。 　Google が検索数の少ない語を伏せるためで、2026-10-14 の実測では 　表示 17,588 対 40,326（56%少ない）でした。表は傾向を見るためのものです。
・平均掲載順位は「表示されたときの平均」です。2ページ目までしか表示されない 　クエリは、そこまで見た人しか数えないので表示回数が過少に出ます。
・このページは毎日13:00に Jenkins が作り直します（tools/gsc_report.py）。 　検索エンジンには出ませんが、URLを知っていれば誰でも見られます。
・ここに無いもの（Search Console を開く必要があるもの）： 　インデックス未登録の理由の一覧（404・リダイレクトエラーなど）／ 　URL検査とインデックス登録のリクエスト（操作）／被リンク（リンク）レポート／ 　手動による対策・セキュリティの問題／ページエクスペリエンス（Core Web Vitals）／ 　拡張（パンくずリスト等）のエラー一覧。いずれも API が提供していません。
