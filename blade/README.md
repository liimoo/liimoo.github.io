# 都市ブレード Web試作版

公開URL: https://japan-map.app/blade/

## 内容

- 47都道府県＋元データの1,747市区町村（計1,794地域）の実輪郭を使う、CPUとの見下ろし型コマ対戦。
- ゲージ切れは0.45秒で減速停止→0.2秒静止→爆発→結果（計1.7秒）。場外は0.4秒飛翔→画面内なら爆発→結果（計1.45秒、画面外へ消えた場合は爆発なしで計0.55秒）。動きを減らす設定では0.35秒の短いフェードのみ。
- 勝者は決着時の速度を引き継いで下寄りへ滑らかに移動し、回転は4秒かけて減速して完全に停止。結果パネルは上部・透明背景で地図を隠さない。
- 地域選択、ドラッグ／タッチ発射、角度・強さによるボタン発射、一時停止、再戦、結果共有。
- 回転スタミナのゲージがゼロ、または場外で決着。ゲージが残る間は回転速度だけで敗北しない。45秒は安全上限で、通常はそれより早く決着する。
- アプリ・対抗戦の記録とは独立。バックエンド・ログイン・オンライン対戦なし。
- ゲームのランタイム依存ライブラリなし。Canvas 2DとES modules。既存GA4へ開始・終了・ストア遷移イベントを送る。

## 構成と地図

`engine.mjs` は描画と独立した純粋関数による物理計算。`app.mjs` が固定120Hzの更新・入力・表示を担当。
衝突は回転した凸包のSAT、同じ質量・最大半径に正規化。床の中央復元力と接触点での角運動量変化を使う。
終盤の停滞を防ぐため、スタミナと回転速度を分離。衝突後は発射時の回転へ徐々に戻し、低速時だけ移動を補助するアーケード調整。速度上限と場外判定は維持する。連続衝突中もゲージが残る間は発射時の回転方向に最低8 rad/s（約1.27回転/秒）を保ち、ゲージゼロで停止する。

`regions.json` はJapanMapの `data/japan_map.json` と `data/prefectures/` にある行政区域を簡略化したもの。
最大の陸地を採用し最大64頂点へ削減、面積重心を原点、最大半径を1に正規化。
出典: 国土交通省 国土数値情報 行政区域データ（N03）を加工、CC BY 4.0。公開画面にも出典・省略範囲を表示。

## 検証

リポジトリのルートから:

```sh
node --test --experimental-test-coverage blade/tests/*.test.mjs
python3 -m http.server 8766 --bind 127.0.0.1
# 別ターミナル（Python Playwright + Chromiumの導入済み環境）
python3 blade/tests/browser_smoke.py http://127.0.0.1:8766
python3 blade/tests/finish_sequences_browser.py http://127.0.0.1:8766
```

- エンジン: 勝敗、凸包接触、薄い形状、同時敗北、速度上限、再現性、個別回転消耗、実地形100試合。
- ブラウザ: 1280/390/320px、地域選択、誤タップ抑止、実タッチイベント発射、停止、決着、再戦、横はみ出し、地図取得失敗。
- Android/iOS実機・Safariでの手触りは継続確認対象。ブラウザのモバイルエミュレーションは実機検証の代わりとはしない。

## 公開

既存のGitHub Pages（main / root）で配信。`play/list/` の案内と `sitemap.xml` に登録。
アプリ本体のバージョンやお知らせは変更しない。試作の地域・ルールを増やすときは、容量だけでなく低速端末での描画と試合時間を確認する。

- 底力は全地域50。消耗割合の2乗に応じ、終盤ほど与える衝突ダメージと回転耐性を補強（式上の最大1.5倍）。攻撃力も全地域50（基本倍率1）。

- 回転力も全地域50で、時間によるゲージ消耗を15％軽減。見た目の回転速度・衝突ダメージへの直接補正はなし。

- 同時ゲージ切れは、0へ丸める前の残量が多い側の勝ち。同値（内部誤差1e-8以内）は引き分け。表示ゲージは0のまま。場外判定が優先。

- SEは `audio/` に必要な9音だけ同梱。原本は共有Audio/se。音ON操作後に読み込み、音OFF・一時停止・再戦で停止。素材対応表は `audio/README.md`。

- 画面はタイトル→地域選択（左のスクロール一覧で都道府県→都市／右に地図／自分・CPU）→VS→対戦→結果。全国対応、2vs2・県対抗戦は準備中。

- `selection-map.json` は全国図、`selection-maps/01.json`〜`47.json` は県を選択した時だけ取得する市区町村地図。JapanMapの `tools/build_blade_regions.py` で対戦用の `regions.json` と一緒に再生成。市区町村数は北方領土6村を含む元データに準拠し、政令指定都市の行政区データは別階層のため含めません。

- 共通能力・質量・最大半径でも、形による勝ちやすさの差は残ります。全国の動作と特徴的な形の対戦診断は `node blade/tests/national_simulation.mjs` で再実行できます。モバイル描画の性能試験ではありません。

- クリティカル：ダメージのある接触の開始時に双方を抽選。確率は `0.08 + 0.08 × (底力/100) × (1−残量)²`、ダメージ1.5倍（1ステップ上限27ポイント）。現在の底力50では8〜12％。100ms以上離れるまで再抽選せず、試合シードに基づく乱数で再現可能。接触点と攻撃側が0.3秒発光し、「クリティカル！」を0.65秒表示。音ON時の金属音は通常衝突と区別しやすい音量に調整。
